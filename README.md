## Development with Node.js

Start a shell such as PoworShell and navigate to the root of the project.

### Installing packages

Install the Node.js package.

```shell
npm install
```

### Execution of development tasks

Execute the following command.

```shell
npm run dev
```

The following URL will take you to the screen.

http://localhost:3000/

- Press "Ctrl + C" to stop

### Execution of Storybook

Execute the following command.

```shell
npm run storybook
```

The following URL will take you to the screen.

http://localhost:6006/

- Press "Ctrl + C" to stop

### Build

Execute the following command to execute the build.

```shell
npm run build
```

### Syntax Check

```shell
npm run lint
```

### Formatter

#### Check

```shell
npm run format
```

#### Check and Format

```shell
npm run format-fix
```

### Formatter (PostCSS)

#### Check

```shell
npm run stylelint
```

#### Check and Format

```shell
npm run stylelint-fix
```

### Upgrading packages

#### Check

```shell
npm run upgrade-check
```

#### Upgrade

```shell
npm run upgrade
```
